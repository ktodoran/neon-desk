Neon Desk widget

The chat in the corner is the widget. This page runs it in demo mode: the answers are scripted from the example help pages in the repository, so it works without a server or a model.

Move the pointer around, type something, or tap the character. Try asking about returns or shipping, asking for a person, or asking something the help pages don’t cover.
